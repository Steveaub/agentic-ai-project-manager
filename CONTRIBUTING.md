# Contributing

Use fictional data, run the automated checks in README.md, and describe the
behavioral change in your pull request. Keep deterministic tools separate from
model prompts. Do not add credentials, actual customer documents, or generated
results presented as verified AI output. New tools need an explicit allowlist
entry, validated inputs and a meaningful failure-path test.

Original project code and fictional examples are MIT licensed. Runtime libraries
retain their own licenses. No external images, fonts or proprietary assets are bundled.
