# 75-second demo script

**0–12s:** “Northstar is my independent LLM Engineering capstone. I'll use the clearly labeled
no-cost fixture so this demonstration is reproducible. The OpenAI integration is implemented
but has not been live-tested.” Enter the default commerce goal, 60 days, $20,000, four people.

**12–27s:** Generate the plan. “Seven work packages become a validated dependency graph.
Python calculates a 45-day schedule and $16,270 estimated cost. These estimates are fictional;
the calculations and tools are real.” Open Timeline and show dependencies and critical work.

**27–40s:** Open Agent activity. “This record shows actual deterministic tool calls. In live
mode, a requirements specialist hands structured context to the planning specialist. The
orchestrator owns permissions and validates outputs independently.”

**40–55s:** Upload the fictional charter in Knowledge and search payment requirements.
“Text is chunked, embedded with local lexical vectors and retrieved with source references.
Live revisions inject these excerpts; the fixed demo attaches them for human review.”

**55–75s:** Preview 46 days and $15,000. “The original work stays intact. There is one day of
schedule buffer and a $1,270 budget shortfall. Save a revision, compare it with the original,
then download the plan. The system reports a tradeoff rather than inventing feasibility.”
