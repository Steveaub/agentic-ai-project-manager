# LinkedIn draft — review before posting

I built Northstar, an independent LLM Engineering capstone: an Agentic AI Project Manager
that makes its planning assumptions, calculations and execution boundaries visible.

The engineering challenge was separating an AI proposal from a plan someone can inspect:

- A requirements-specialist → planning-specialist handoff using Pydantic structured outputs.
- A bounded Python orchestrator with five allowlisted calculation/validation tools.
- Critical-path analysis, pooled resource leveling, budget calculations and revision history.
- Document ingestion and source-linked lexical vector retrieval for planning context.
- A responsive dashboard, scenario comparison, trace inspection and JSON/CSV export.

The reproducible demo makes zero model calls and is labeled as a fictional template. With a
$20,000 / 60-day launch target, its estimates calculate to $16,270 and 45 days. Reducing the
budget to $15,000 and the target to 46 days preserves the work and exposes the budget shortfall.

Local validation: 30 Python tests and 13 browser assertions passed. The real OpenAI path is
implemented but still needs authorized paid evaluation; semantic embeddings and a second model
provider remain on the roadmap. I value that distinction more than a long list of claimed features.

This is an independently developed project inspired by my LLM engineering learning, not a claim
of a formally graded course assignment. Source, architecture, demo and limitations:
https://github.com/Steveaub/agentic-ai-project-manager
